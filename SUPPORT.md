# Support

Need help with `pdfnative-mcp`? Here's where to go:

- 🐛 **Bug?** [Open an issue](https://github.com/Nizoka/pdfnative-mcp/issues/new?labels=bug).
- ✨ **Feature request?** [Open an issue](https://github.com/Nizoka/pdfnative-mcp/issues/new?labels=enhancement) or a PR.
- ❓ **Question?** [Start a discussion](https://github.com/Nizoka/pdfnative-mcp/discussions) or check existing threads first.
- 🔐 **Security issue?** Read [SECURITY.md](SECURITY.md) — please **do not** open a public issue.
- 📦 **PDF engine bugs** (rendering, encoding, signature validation): file upstream at [Nizoka/pdfnative](https://github.com/Nizoka/pdfnative/issues).
- 🤖 **MCP protocol questions**: see [modelcontextprotocol.io](https://modelcontextprotocol.io) or the [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk).

We aim to triage issues within 5 business days. This is an open-source project maintained by volunteers — please be patient and constructive.
