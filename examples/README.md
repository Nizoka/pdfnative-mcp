# Examples

51 executable `tools/call` sequences, one JSON file each: `{ "description", "tool", "arguments" }` for a single call, or `{ "description", "steps": [ { "tool", "arguments" }, … ] }` for a chain whose later steps take the earlier output. `npm run examples:check` (tests/examples.test.ts) runs every file live against the server; `npm run test:generate` renders them into the sample byte baseline (tests/_fixtures/samples.sha256.json). A new engine option gets an example here before it ships (tests/engine-surface.test.ts holds the matrix to the tree).
