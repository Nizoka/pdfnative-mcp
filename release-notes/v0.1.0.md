# pdfnative-mcp v0.1.0

<!-- GitHub Release title: v0.1.0 - Initial MCP bridge release -->

_Released 2026-04-26_

v0.1.0 is the first public release of pdfnative-mcp, an MCP stdio server that bridges
pdfnative for production-grade PDF generation from AI clients.

100% backward-compatible baseline release.

## Highlights

- MCP stdio server with four tools: generate_basic_pdf, add_barcode, add_international_text, sign_pdf.
- Strict schema validation for each tool (JSON Schema + runtime Zod validation).
- Secure output sandbox model via PDFNATIVE_MCP_OUTPUT_DIR.
- Supports inline base64 or file output mode.

## Added

- **feat(server):** initial MCP server implementation for stdio transport.
- **feat(tools):** added generate_basic_pdf tool.
- **feat(tools):** added add_barcode tool.
- **feat(tools):** added add_international_text tool with bundled multilingual font loading.
- **feat(tools):** added sign_pdf tool wrapping pdfnative digital signature API.
- **feat(security):** added sandboxed file output constraints and path traversal protections.
- **feat(ci):** added CI and publish automation workflows.
- **feat(docs):** added README, CONTRIBUTING, SECURITY, SUPPORT, CODE_OF_CONDUCT.

## Documentation

- **docs(release):** added release-notes/TEMPLATE.md and release-notes/v0.1.0.md.
- **docs(governance):** added issue templates, CODEOWNERS, dependabot, and KB instructions/prompts under .github.
